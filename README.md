# COVID-19 Data Analysis using PySpark

## Project Description
This project is about analyzing COVID-19 dataset using PySpark in Anaconda Prompt. The data is processed to get useful insights like total cases, deaths, and continent-wise statistics.

## Objective
To analyze COVID-19 data and perform operations like filtering, sorting, and aggregation using PySpark.

## Tools Used
- Python  
- PySpark  
- Anaconda Prompt  
- CSV Dataset  

## How Project Works
- Spark session is started in Anaconda Prompt  
- Dataset is loaded using PySpark  
- Data is processed using different commands  
- Results are shown in terminal  

## Commands Used
- read.csv()  
- show()  
- printSchema()  
- filter()  
- select()  
- groupBy()  
- agg()  
- orderBy()  
- drop()  
- write.csv()
